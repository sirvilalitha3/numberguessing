# 🎯 Number Guessing Game

A simple Python number guessing game where the user tries to guess a randomly generated number.

This project was first created using basic Python concepts and later upgraded using **functions, data structures, modules, and error handling**.

## 📌 Original Version

The first version of the game used:

* `while` loop
* `if / elif / else`
* `input()`
* Basic comparison operators

## 🚀 Upgraded Version

The upgraded version uses:

* **Functions** – Divided the program into smaller, reusable functions.
* **Random Module** – Generates a random secret number using `random.randint()`.
* **List** – Stores all the guesses made by the user.
* **Error Handling** – Uses `try-except` to handle invalid input.
* **While Loop** – Keeps the game running until the correct number is guessed.
* **If / Elif / Else** – Checks whether the guess is too high, too low, or correct.

## 🎮 How the Game Works

1. The program generates a random number between 1 and 100.
2. The user enters a guess.
3. The program checks whether the input is valid.
4. The guess is stored in a list.
5. The program gives a hint:

   * Too high
   * Too low
   * Correct
6. When the user guesses correctly, the total number of attempts and all previous guesses are displayed.
